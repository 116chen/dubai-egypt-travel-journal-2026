# 一路，记下来。· React 旅行图册

一个可以运行、修改和构建的私人旅行图册。以暖米白、苔绿和陶土色组织真实旅行照片，世界地图和国家筛选连接五段旅程，日本春季与初夏的旅行分别成册。React 19、Mantine 8.3、TypeScript 与 Vite。

视觉采用柔和的照片圆角、浅色标签和轻阴影，以留白连接各段内容；地图移除方格网，路线和地点指引使用经过原有地点坐标的弧线。原有埃及地图也使用相同的线条处理，连线仍为旅程示意。

配色参考 `theme-factory` 的 Forest Canopy 与 Desert Rose，结合相册照片调整为自然旅行主题。暖米白 `#f7f3ea` 用于背景，苔绿 `#4b624b` 用于控件，深绿 `#293c31` 用于世界足迹，陶土 `#9b5945` 点缀章节与路线。灰绿文字加深以兼顾小字阅读，手机高清查看使用深色背景。所有主题色及 Mantine 色阶集中在 `src/theme.ts`，具体应用在 `src/styles/palette.css`。

共 **5 个国家、5 段旅程、37 天、611 张照片**。新增 416 张相册照片，原有 195 张埃及与迪拜照片完整保留。

新增照片来自用户授权读取的 Apple Photos 相册，经联系表逐张挑选，去除截图、证件、近似连拍和重复版本。手机照片与无定位的相机照片一同整理。日期使用当地时区；部分 Panasonic RAW 的时区与同名 JPEG 不一致，按照配对照片确认的相机时间校正。来源、调整记录与地点证据见 `PHOTO-SOURCES.json`。

新增手记支持地点地图、逐日照片目录、日期和地点筛选、文字搜索、分页、高清查看、键盘翻图和手机滑动。每段旅程有独立小记，支持草稿暂存、保存与 Markdown 导出。

四册默认打开“旅行手记”，共12段照片章节、25篇逐日短记和28处地点介绍。章节结合风景、人物与旅途日常，按相册中可见的内容撰写；每篇逐日短记配当天拍摄的封面和全部当天照片。阅读侧栏支持前一天、后一天、刷新恢复与进入当天相册；章节中的地点链接联动地图，地点页可继续上一站、下一站。每册的小记提示围绕该段旅程，个人补写与草稿继续使用原来的存储键。

日本两册的“照片之外”收录作者提供的14段回忆：第一次9段、第二次5段。保留第一人称感受，未补充不确定的日期、币种或人物身份。回忆正文在 `src/trip-memories.ts`，随网站发布；浏览器中的既有小记与草稿保持原值，可继续补写。Markdown导出包含回忆、正式补写和未提交草稿。封面提供“读我的小记”入口，`?trip=japan-spring#trip-notes` 与 `?trip=japan-summer#trip-notes` 可直接打开对应小记。

关西抵达当天的三张飞机与机场照片归为“关西机场”，两张机场照片GPS约为34.43023 N、135.238625 E。此前按最近城市归为神户；这次在展示数据中校正，神户保留27张照片。校正依据记录在 `PHOTO-SOURCES.json`，原始相册数据快照不变。

照片包含长边最高 2200px 的高清版本、1200px 预览和 480px 缩略图，页面按显示尺寸选择资源。地点预览优先展示代表性照片，相册保持拍摄顺序；新西兰湖区的密集编号使用指引线分开，手机世界地图下方提供可直接点击的国家入口。

## 启动

需要 Node.js 20.19+ 或 22.12+。开发验证使用 Node.js 20.20.1。

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:5186 。

## 构建与预览

```bash
npm run build
npm run preview
```

构建文件在 `dist/`，预览地址为 http://127.0.0.1:4186 。将 `dist/` 内的文件交给静态网站托管服务即可。项目使用相对资源路径，也支持站点子目录。

GitHub 仓库：https://github.com/116chen/dubai-egypt-travel-journal-2026  
在线图册：https://116chen.github.io/dubai-egypt-travel-journal-2026/

`main` 保存可编辑的React项目，`gh-pages` 保存构建后的网页。GitHub Pages使用 `gh-pages` 分支的根目录，推送该分支后自动更新。后续发布应先运行 `npm run build`，再以普通Git提交更新发布分支，保留发布历史。

React 构建结果需要通过 HTTP 服务打开。相册、字体、地图和旅行数据均随项目打包，访问页面不依赖在线图片、地图服务或 CDN；点击历史资料链接时会打开相应来源网站。

## 保留的埃及与迪拜内容

- 三组地图：埃及、迪拜、航线，共21组地点；照片与地点联动，可查看相关历史、旅行小记和逐日行程。手机选点直接展开底部照片面板，支持上一站、下一站。
- 195张照片，支持国家、拍摄日期筛选、分页、放大、键盘左右切换和手机滑动翻图。竖图完整展示，高清查看预加载下一张。
- 13篇历史背景、7段旅行章节，以及可点击的资料引用。
- 12天行程、5段航班、5段住宿与26项原单参考项目。
- 四件旅行小事：过马路靠运气、无牌车辆在高速开门行驶、灌了红海水、埃及饭菜“变形记”。支持补写、草稿自动暂存、长文展开与 Markdown 导出。

金字塔实际到访为 **2026年10月8日，开罗最后一天**。原计划与照片记录的差异保留在行程说明中。已移除阿布辛贝自拍 `IMG_9477.JPG`。

小记与草稿保存到当前站点的浏览器本地存储；关闭编辑、按 Esc 或刷新后可以继续补写。保存后才替换正式小记，导出同时包含已有小记和暂存草稿。更换设备、浏览器或网站地址时，需要通过“导出小记”留存。

旅程、国家筛选、相册页码、筛选、地图地点及正在阅读的章节写入 URL；刷新后可以恢复。切换旅程支持浏览器前进、后退。新增地图站点用于沿照片地点浏览，连线是示意，不代表精确行驶轨迹。

直接打开 `?trip=new-zealand`、`?trip=jeju`、`?trip=japan-spring`、`?trip=japan-summer` 或 `?trip=egypt-dubai` 可进入对应手记；`?trip=all&destination=jp` 打开日本旅行目录。`tripView=story/route/photos` 切换手记、地图和相册，`tripRead=2026-04-27` 恢复某天的逐日手记。旧版埃及与迪拜的标签页、地图和阅读链接仍可使用。

## 项目结构

```text
src/
  App.tsx                  图册入口、旅程导航与浏览器历史
  EgyptJournal.tsx         原有埃及与迪拜手记
  atlas.ts                 图册数据类型、旅程和国家索引
  trip-editorial.ts         照片章节、逐日短记、地点介绍与小记提示
  trip-memories.ts          作者提供的日本两次旅行小记
  main.tsx                 Mantine 主题与 React 挂载
  theme.ts                 自然旅行配色、色阶与CSS变量
  styles.css               主题与原有手记样式
  styles/                  图册、地图、内容、手机与配色样式
  data.ts                  数据类型、索引与资源路径
  hooks.ts                 URL 状态
  story-notes.ts            小记与草稿保存
  data/
    journal.json           全部照片与四件小事
    map.json               地点、地图轮廓与示意路线
    content.json           章节、历史、行程、表格和来源
    photo-layout.json      图片尺寸与封面裁切重点
    atlas.json             新增四段旅行、照片、地点与局部地图
    world.json             世界地图轮廓
  components/
    AtlasOverview.tsx      摄影封面、旅程目录与世界地图
    WorldMap.tsx           可选择国家的世界地图
    AtlasTrip.tsx          新手记的地图、逐日目录与相册
    TripStory.tsx          照片章节与逐日阅读目录
    TripDayReader.tsx      逐日短记、当天照片与前后日导航
    route-path.ts          地图弧线路径与地点指引
    TripNotes.tsx          新手记的独立小记与草稿
    TravelMap.tsx          地图与地点照片
    PlaceDetails.tsx       电脑侧栏与手机照片面板的共用内容
    JournalImage.tsx       按显示尺寸选择图片版本
    Gallery.tsx            相册
    Readings.tsx           历史目录
    Itinerary.tsx          行程与资料表
    JournalDrawer.tsx      历史、章节和逐日阅读侧栏
    PhotoViewer.tsx        照片查看器
    Stories.tsx            小记编辑与导出
public/
  assets/photos/           照片
  assets/thumbs/           缩略图
  assets/previews/         中等尺寸预览图
  fonts/                   本地字体与许可证
```

技术栈：React 19、TypeScript 5.9、Vite 6、Mantine 8.3、Lucide React。生产构建按 React、Mantine 与页面代码分包，相册、历史目录和行程面板按需加载。

照片均为用户相册中的旅行素材。地图使用 Natural Earth 1:110m 与 1:50m 公共领域数据，随项目打包；新增地图显示地点中心，个别无定位相机照片依据可识别地标和附近拍摄时间归入地点组。字体许可证见 `public/fonts/`。图册可本地运行，也通过GitHub Pages发布。旧版 `dubai-egypt-journey.html` 和 `dubai-egypt-journal-v5.html` 链接保留，跳转时保留查询参数；埃及小记继续使用 `nile-gulf-journal-v3-notes`，同一浏览器在原网站保存的小记可以继续读取。
